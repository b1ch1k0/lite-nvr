მუშაობს კომფორტულად **2 vCPU / 2 GB RAM**-ზე ექვსი კამერით. ვიდეო ჩაწერისთვის **არასდროს გადაიკოდება** —
ნაკადი პირდაპირ MP4-ში იწერება, ასე რომ პროცესორი თავისუფალი რჩება მოძრაობის დეტექციისთვის.

## 🚀 დაყენება

**Ubuntu / Debian / Rocky / Alma / RHEL 9 — ერთ ხაზში:**

```bash
curl -fsSL https://raw.githubusercontent.com/b1ch1k0/lite-nvr/main/install.sh | sudo bash -s -- --tz Asia/Tbilisi
```

პარამეტრები `bash -s --`-ის შემდეგ იწერება:

| პარამეტრი | ნაგულისხმევი | |
|---|---|---|
| `--port N` | `80` | სხვა პორტი, თუ 80 დაკავებულია ან nginx-ზე უკვე სხვა საიტებია |
| `--tz Zone/City` | სისტემური | ჩანაწერები ადგილობრივი დროით ინომრება (მაგ. `Asia/Tbilisi`) |
| `--admin NAME` | `admin` | პირველი ადმინისტრატორის სახელი |
| `--keep-default-site` | — | nginx-ის ნაგულისხმევი საიტი არ წაიშალოს (Debian/Ubuntu) |

ბოლოს ინსტალერი დაბეჭდავს **შესვლის ბმულს**, მომხმარებელსა და პაროლს (ასევე ინახება `/root/nvr-admin.txt`-ში):

```
════════════════════════════════════════════════════════════
  NVR is ready
  login:    http://192.168.1.50/s/Xq7pL2mN9vR4tK8w
  user:     admin
  password: ****************
  Every other URL answers 404 — bookmark the link.  sudo nvrctl link
════════════════════════════════════════════════════════════
```

> ⚠️ ყველა სხვა მისამართი **404**-ს აბრუნებს — ეს ბმული დაიმახსოვრეთ/შეინახეთ. დაკარგვის შემთხვევაში: `sudo nvrctl link`.

## 🧭 პირველი ნაბიჯები

1. გახსენით შესვლის ბმული და შედით.
2. **კამერები → ONVIF ძებნა** (ან **+ კამერის დამატება** ვენდორის შაბლონით).
   *Tapo:* ჯერ Tapo აპში შექმენით *Camera Account* და გამოიყენეთ ONVIF პორტი `2020`.
3. **მომხმარებლები** → დაამატეთ ხალხი და მონიშნეთ, ვის რომელი კამერა უჩანს.
4. **შენახვა** → ვადა დღეებში, არჩევით ღრუბელზე/SFTP-ზე გადმოტვირთვა.
5. შეცვალეთ პაროლი და შეინახეთ შესვლის ბმული: *თქვენი სახელი (ზედა მარჯვენა კუთხე)*.

## 📖 დეტალური განხილვა

### კამერების დამატება
სამი გზაა:

- **ავტომატური დადგენა** — ONVIF გვერდზე შეიყვანთ IP-ს + მომხმარებელს/პაროლს, სისტემა სკანირებს კამერების
  გავრცელებულ პორტებს (RTSP 554/8554, ONVIF 80/2020/8000/8899, Hikvision/Dahua SDK), ამოწმებს ONVIF-ს და
  ვენდორების RTSP-გზებს, შემდეგ აღმოჩენილს ერთ დაჭერაში ამატებს.
- **ONVIF ძებნა** — multicast აღმოჩენა პლუს ქვექსელის unicast სკანი (სხვადასხვა VLAN-ზეც), ნაკადის
  მისამართები თავად ივსება.
- **ხელით შაბლონით** — Tapo/VIGI, Hikvision/HiWatch/EZVIZ, Dahua/IMOU/Amcrest, Uniview, Reolink, Axis,
  XMEye (DVRIP), ან **„სხვა — ხელით"**, რომელიც იღებს **ნებისმიერ პროტოკოლსა და პორტს**:
  `rtsp://`, `rtsps://`, `http://` (FLV/MJPEG), `onvif://`, `dvrip://`.

**NVR/DVR და არასტანდარტული პორტი.** თუ NVR გარედანაა გადამისამართებული (port forwarding), პორტის ველში
ჩაწერეთ **გარე RTSP პორტი** (მაგ. `7233`), ხოლო არხის ველში — არხის ნომერი. Hikvision-ზე ნაკადის მისამართი
`/Streaming/Channels/<არხი>01` (მთავარი) და `<არხი>02` (დამხმარე). შენახვამდე ღილაკი **ტესტი** ამოწმებს,
რეალურად უკავშირდება თუ არა ნაკადს.

### ცოცხალი ყურება
ბადე აჩვენებს ყველა კამერას. **ხარისხი** ბრაუზერზე ინახება: *მაღალი* უკრავს მთავარ ნაკადს, *დაბალი* —
მსუბუქ დამხმარეს. ლოკალურ ქსელში ნაგულისხმევად მაღალია, ინტერნეტიდან — დაბალი, რომ ატვირთვა არ გაიჭედოს.

**ფანჯრის გადიდება:** დააჭირეთ თავად ფანჯარას (არა ცალკე ხატულას) — ანიმაციით გაიშლება. გადიდებისას ის
კამერა მთავარ (სრული ხარისხის) ნაკადზე გადადის, ხოლო დანარჩენი ფანჯრები კავშირს წყვეტენ, რომ ზედმეტი
ტრაფიკი არ წამოვიდეს. 4:3 კამერა ბადესა და გადიდებისას 16:9 ჩარჩოს ავსებს (ოდნავ იჭრება); სრული კადრი ცალკე
ერთი-კამერის გვერდზე ჩანს.

### ჩაწერა
კამერაზე სამი რეჟიმია: **გამორთული / 24-7 / მხოლოდ-მოძრაობა**. ვიდეო **არ გადაიკოდება** — ნაკადი პირდაპირ
იწერება ~1-წუთიან MP4 სეგმენტებად, მოძრაობის გარშემო ისხლიტება. watchdog გაჩერებულ ნაკადს ავტომატურად
თავიდან უშვებს.

### მოძრაობის დეტექცია
მუშაობს **დამხმარე ნაკადზე** (≈3 % CPU კამერაზე). უგულებელყოფს სინათლის ჩართვა-გამორთვას, IR დღე/ღამის
გადართვას და ეკრანზე დატანილ საათს, ასე რომ ცრუ განგაშები მცირდება. მოვლენებს სურათებით ინახავს.

### PTZ (ტრიალი/დახრა/ზუმი)
ONVIF-ის მქონე კამერებზე — პანორამა, დახრა, ზუმი, სიჩქარე, პრესეტები და კლავიატურის ისრები.
„dead-man" დაცვა: ბრაუზერის გათიშვისას კამერა თავისით ჩერდება.

### მომხმარებლები და 2FA
როლები: **ადმინი / ოპერატორი / მნახველი**, თითოეულს ცალ-ცალკე ენიჭება კამერები. ყველა ქმედება აუდიტის
ჟურნალში იწერება. არჩევით ჩაირთვება **ორფაქტორიანი შესვლა (TOTP)**: QR-კოდით რეგისტრაცია Google
Authenticator / Authy და მსგავსებში; დაბლოკილ მომხმარებელს ადმინს შეუძლია 2FA გაუუქმოს.

### შენახვა და გადმოტვირთვა
ვადა დღეებში, დისკის დაცვა (დაბალ ადგილზე ჩაწერა ჩერდება). ჩანაწერები შეიძლება ავტომატურად გადაიტვირთოს
**Google Cloud Storage**-ზე ან **SFTP**-ზე (rclone-ით).

### იერსახე და მობილური
ტერმინალური / ნეონის **„cyber" თემა** (digital-rain შესვლა, scanline-ები). პანელი ადაპტურია და ტელეფონზეც
სრულად მუშაობს — iPhone Safari-ზე ცოცხალი ფანჯრები თავისით ეშვება (play ღილაკის გარეშე), ფორმის ველები 16px
(ფოკუსისას არ ზუმდება), განიერი ცხრილები გადაიქაჩება.

## 🔐 უსაფრთხოება

- **დამალული შესვლის მისამართი** — `/s/<შემთხვევითი>`; ყველა სხვა URL 404-ია.
- **proof-of-work შესვლა** + **სიხშირის შეზღუდვა** (10 შეცდომა / 10 წთ IP-ზე) — ავტომატიზებული შეტევის წინააღმდეგ.
- **პაროლები** scrypt-ით ჰეშირებული; **TOTP 2FA** არჩევით.
- **სუფთა IP-ზე შესვლა** — არჩევით (`/account`): შესვლა `http://<ip>/`-ზეც, დამალული ბმულის გარდა.
- კამერების მომხმარებლები/პაროლები **მხოლოდ ბაზაშია** (`/var/lib/nvr/nvr.db`), არასდროს კოდში/რეპოში.
- დეტალურად: [SECURITY.md](SECURITY.md).

## 🛠 nvrctl

```bash
sudo nvrctl link          # დამალული შესვლის ბმული
sudo nvrctl new-link      # ახალი ბმული (ძველი ითიშება)
sudo nvrctl reset-admin   # დავიწყებული პაროლი → ახალი შემთხვევითი
sudo nvrctl status        # სერვისები, დისკი, ვერსია
```
