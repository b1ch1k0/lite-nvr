# 📹 lite-nvr — ქართულად

მსუბუქი ვიდეოსამეთვალყურეო სისტემა Linux-ისთვის: ცოცხალი ყურება, ჩაწერა, მოძრაობის დეტექცია, ONVIF და PTZ.
2 CPU / 2 GB RAM-ზე 6 კამერას თავისუფლად ემსახურება. ვიდეო ჩაწერისას არ გადაიკოდება.

## დაყენება (Ubuntu, Debian, Rocky, Alma, RHEL 9)

```bash
curl -fsSL https://raw.githubusercontent.com/b1ch1k0/lite-nvr/main/install.sh | sudo bash -s -- --tz Asia/Tbilisi
```

ბოლოს ეკრანზე გამოჩნდება **შესვლის ბმული**, სახელი და პაროლი (ასევე `/root/nvr-admin.txt`).
ყველა სხვა მისამართი 404-ს აბრუნებს — ბმული შეინახეთ. დაკარგვის შემთხვევაში: `sudo nvrctl link`.

| პარამეტრი | |
|---|---|
| `--port 8080` | თუ 80 დაკავებულია ან nginx-ზე სხვა საიტებიც არის |
| `--tz Asia/Tbilisi` | ჩანაწერების ფაილები ადგილობრივი დროით |
| `--admin სახელი` | პირველი ადმინის სახელი |

**RPM (Rocky/Alma/RHEL 9):** იხ. [README.md](README.md#-install) → *RPM package*.

## პირველი ნაბიჯები
1. შედით ბმულით.
2. **კამერები → ONVIF ძებნა** ან **+ კამერის დამატება**. Tapo-ზე ჯერ აპში შექმენით *Camera Account* (ONVIF პორტი 2020).
3. **მომხმარებლები** — როლი (ადმინი / ოპერატორი / მნახველი) და რომელ კამერებზე ჰქონდეს წვდომა.
4. **შენახვა** — ვადა დღეებში, Google Cloud ან SFTP-ზე გადატანა.

## სასარგებლო ბრძანებები
```bash
sudo nvrctl link          # შესვლის ბმული
sudo nvrctl new-link      # ახალი ბმული (ძველი გაითიშება)
sudo nvrctl reset-admin   # დაკარგული პაროლი
sudo nvrctl status        # სერვისები, დისკი, ვერსია
sudo /opt/nvr/deploy/add-disk.sh /dev/sdb    # ცარიელი დისკი → ჩაწერის დისკი
```

განახლება: იგივე ერთხაზიანი ბრძანება (კამერები, მომხმარებლები, ჩანაწერები რჩება).
წაშლა: `sudo /opt/nvr/deploy/uninstall.sh` (მონაცემები რჩება) ან `--purge`.
